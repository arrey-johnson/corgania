# Corgania — Africa's Global B2B Trading Ecosystem

Private, membership-based B2B trading platform connecting verified African producers,
manufacturers and exporters with qualified international bulk buyers.

- **Stack:** Next.js 15 (App Router) · TypeScript strict · Tailwind v4 · Supabase (Postgres/Auth/Storage/RLS/Realtime)
- **Start here:** `docs/ENVIRONMENT_SETUP.md` · architecture in `docs/ARCHITECTURE.md` · progress in `docs/BUILD_PROGRESS.md`
- **Run:** `npm install && npm run dev` (public site works without Supabase keys; private areas show a setup gate)

```bash
npm run typecheck && npm run lint && npm test && npm run build
```
